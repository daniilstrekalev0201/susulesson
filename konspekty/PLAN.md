# Конспекты для бота — план и правила

Запрос пользователя (11.10.2026): по каждому предмету текущего семестра П-377 — ОТДЕЛЬНЫЙ PDF на КАЖДУЮ лекцию,
«не сильно сжато, немного подробнее» (без выводов формул), оформление по СТО ЮУрГУ 04–2008
(рамка, основная надпись форма 2/2а, титульный, ОГЛАВЛЕНИЕ, разделы, «Выводы по разделу …», формулы с «где»,
БИБЛИОГРАФИЧЕСКИЙ СПИСОК по ГОСТ 7.1 — только проверенные данные).

Исходники: konspekty/src/<предмет>/_subject.txt + NN.txt; сборка `python konspekty/build.py [предмет]`
→ konspekty/pdf/<предмет>/NN.pdf и pdf/index.json (для бота). Черновики старого формата — src/_drafts/.

Материалы курсов читаются во встроенном браузере (edu.susu.ru, вход делал пользователь):
