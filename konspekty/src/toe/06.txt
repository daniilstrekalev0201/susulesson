@title Особые режимы работы длинной однородной линии

= ВВЕДЕНИЕ

В лекции рассмотрены коэффициент отражения и режим согласованной нагрузки, линия без потерь, согласованная нагрузка линии без потерь, режимы холостого хода и короткого замыкания и входное сопротивление линии.

# Коэффициент отражения и согласованная нагрузка

## Коэффициент отражения

Обратная волна существует, если нагрузка не согласована с волновым сопротивлением: Z_{н} ≠ Z_{с}. Отношение комплекса напряжения (тока) обратной волны в конце линии к комплексу прямой волны в конце называют коэффициентом отражения:

$ n = U_{обр}(0)/U_{пр}(0) = (Z_{н} – Z_{с})/(Z_{н} + Z_{с}).

Наибольшие по модулю значения n – в режимах холостого хода (Z_{н} = ∞, n = 1) и короткого замыкания (Z_{н} = 0, n = –1): полное отражение. Чем больше |n|, тем неравномернее распределены вдоль линии действующие значения напряжения и тока; при несогласованной нагрузке часть энергии отражённой волной возвращается к источнику.

## Режим согласованной нагрузки

При Z_{н} = Z_{с} коэффициент отражения n = 0 и обратной волны нет:

$ U = U_{2}·e^{γx};  I = I_{2}·e^{γx},
| где x отсчитывается от конца линии.

Действующие значения напряжения и тока вдоль линии меняются по экспоненте, вся энергия, поступающая в нагрузку, ею потребляется. При несогласованной нагрузке отражённая волна возвращается к началу; если сопротивление генератора не равно Z_{с}, возникает повторное отражение, и в нагрузку приходит ложный сигнал: в телефонных линиях – неразборчивость речи, в телевидении – многоконтурность изображения. Поэтому линии передачи информации, как правило, согласуют.

> n = (Z_{н} – Z_{с})/(Z_{н} + Z_{с}); холостой ход n = 1, КЗ n = –1, согласованная нагрузка n = 0.
> В согласованном режиме отражённой волны нет, вся энергия поглощается нагрузкой.

# Линия без потерь

## Параметры линии без потерь

Если потери много меньше мощности нагрузки (линии, соединяющие аппаратуру с антеннами), принимают R_{0} = 0 и G_{0} = 0. Тогда:

$ Z_{с} = √(L_{0}/C_{0});  γ = jω√(L_{0}C_{0});  α = 0;  β = ω√(L_{0}C_{0});  v = 1/√(L_{0}C_{0}).

Волновое сопротивление чисто активное и не зависит от частоты (θ = 0 – напряжение и ток каждой волны совпадают по фазе); затухания нет; коэффициент фазы пропорционален частоте, фазовая скорость от частоты не зависит – линия без потерь является линией без искажений.

Гиперболические функции комплексного аргумента заменяются круговыми функциями действительного: ch jβx = cos βx, sh jβx = j·sin βx:

$ U = U_{2}·cos βx + jZ_{с}·I_{2}·sin βx;  I = j(U_{2}/Z_{с})·sin βx + I_{2}·cos βx.

При несогласованной нагрузке амплитуды прямой и обратной волн вдоль линии постоянны, а результирующие действующие значения распределены неравномерно.

## Согласованная нагрузка линии без потерь

При Z_{н} = Z_{с} мгновенные значения u(x, t) = U_{2m}·sin(ωt + βx), i(x, t) = I_{2m}·sin(ωt + βx): напряжение и ток вдоль линии меняются синусоидально с постоянной амплитудой и совпадают по фазе, действующие значения не зависят от координаты. Мощность волны P = U_{2}^{2}/Z_{с} полностью поглощается нагрузкой. Из Z_{с} = U/I = √(L_{0}/C_{0}) следует L_{0}I^{2}/2 = C_{0}U^{2}/2: энергия поровну распределена между магнитным и электрическим полями.

> Линия без потерь: Z_{с} активное, α = 0, v не зависит от частоты – линия без искажений.
> При согласованной нагрузке действующие значения U и I постоянны вдоль линии, энергия полей распределена поровну.

# Входное сопротивление линии

## Общее выражение

Входное сопротивление линии – сопротивление двухполюсника, который можно подключить к генератору вместо линии без изменения режима генератора:

$ Z_{вх} = U_{1}/I_{1} = Z_{с}·(Z_{н} + Z_{с}·th γl)/(Z_{с} + Z_{н}·th γl).

Оно зависит от параметров линии, её длины, частоты и сопротивления нагрузки; через коэффициент отражения Z_{вх} = Z_{с}·(1 + n·e^{–2γl})/(1 – n·e^{–2γl}).

## Холостой ход и короткое замыкание

$ Z_{кз} = Z_{с}·th γl;  Z_{хх} = Z_{с}·cth γl.

Сопротивления Z_{хх} и Z_{кз} легко измерить опытным путём, а по ним вычислить вторичные параметры линии:

$ Z_{с} = √(Z_{хх}·Z_{кз});  th γl = √(Z_{кз}/Z_{хх}).

Входное сопротивление можно выразить и через них: Z_{вх} = Z_{хх}·(Z_{н} + Z_{кз})/(Z_{н} + Z_{хх}). У линии без потерь при согласованной нагрузке n = 0 и Z_{вх} = Z_{с} – чисто активно при любой длине линии.

> Z_{вх} = Z_{с}(Z_{н} + Z_{с}th γl)/(Z_{с} + Z_{н}th γl).
> Опыты ХХ и КЗ дают вторичные параметры: Z_{с} = √(Z_{хх}Z_{кз}), th γl = √(Z_{кз}/Z_{хх}).
