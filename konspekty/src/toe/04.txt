= ВВЕДЕНИЕ

В лекции рассмотрены ещё три метода расчёта переходных процессов в нелинейных цепях: метод условной линеаризации (на примере включения катушки со стальным сердечником на синусоидальное напряжение), метод аналитической аппроксимации и численный метод последовательных интервалов.

# Метод условной линеаризации

## Идея метода

Для цепи из резистора и нелинейной катушки по второму закону Кирхгофа u = R·i + dψ/dt. Если u_{R max} << u_{L max}, нелинейностью в первом слагаемом можно пренебречь, заменив ток через потокосцепление с постоянной эквивалентной индуктивностью i = ψ/L_{э}:

$ (R/L_{э})·ψ + dψ/dt = U_{m}·sin(ωt + ψ_{u}).

Получено линейное уравнение первого порядка, которое решают классическим или операторным методом. Главное – выбор L_{э}: её находят по точке установившегося режима после коммутации. Так как напряжение на резисторе мало, всё напряжение приложено к катушке: Ψ_{m} ≈ U_{m}/ω; по кривой ψ(i) находят амплитуду тока I_{m} и L_{э} = Ψ_{m}/I_{m} (в примере лекции I_{m} = 3,51 А, L_{э} = 1,09 Гн).

## Решение

Принуждённая составляющая ψ_{пр} = Ψ_{m}·sin(ωt + ψ_{u} – φ), где

$ Ψ_{m} = U_{m}/√(ω^{2} + (R/L_{э})^{2});  tg φ = ωL_{э}/R.

Свободная составляющая ψ_{св} = A·e^{pt}, p = –R/L_{э}; A находят из ψ(+0) = ψ(–0) = 0: A = –Ψ_{m}·sin(ψ_{u} – φ). Свободная составляющая максимальна, когда sin(ψ_{u} – φ) = ±1; в примере при ψ_{u} = –6,7° получено ψ(t) = 3,8·sin(314t – 90°) + 3,8·e^{–36,7t} Вб, время процесса около 0,11 с.

По кривой ψ(t) и характеристике ψ(i) строят ток. Если у линейной катушки ударный ток не превышает удвоенной амплитуды установившегося, то у катушки со сталью из-за насыщения i_{max} = 12,4 А – в 3,5 раза больше амплитуды I_{m} = 3,51 А. Это объясняет броски тока включения трансформаторов.

> Условная линеаризация: нелинейный элемент заменяют постоянным L_{э}, найденным по установившемуся режиму после коммутации.
> Поток рассчитывают как в линейной цепи, ток – по характеристике ψ(i); из-за насыщения бросок тока многократно больше амплитуды.

# Метод аналитической аппроксимации

## Суть метода

Характеристику нелинейного элемента заменяют аналитической функцией, при которой нелинейное уравнение интегрируется в квадратурах. Например, при включении катушки на постоянное напряжение U через сопротивление R:

$ R·i + dψ/dt = U;  i = a·ψ^{2},
| где a – коэффициент аппроксимации, находимый по точке установившегося режима: I_{∞} = U/R = a·Ψ_{∞}^{2}.

## Решение

Вводят относительные величины x = ψ/Ψ_{∞} и τ = U·t/Ψ_{∞}; уравнение принимает вид x^{2} + dx/dτ = 1. Разделяя переменные, получают τ = 0,5·ln((1 + x)/(1 – x)), откуда

$ x = (1 – e^{–2τ})/(1 + e^{–2τ}) = th τ;  ψ(t) = Ψ_{∞}·th(U·t/Ψ_{∞});  i(t) = I_{∞}·th^{2}(U·t/Ψ_{∞}).

Можно использовать и другие аппроксимации, например динамической индуктивности L_{д}(i) = b/(a + i); тогда решение также выражается через экспоненты. Результаты разных аппроксимаций близки к результату кусочно-линейного метода.

> Аналитическая аппроксимация: характеристику задают функцией (например, i = aψ^{2}), допускающей точное интегрирование.
> Для i = aψ^{2}: ψ(t) = Ψ_{∞}·th(Ut/Ψ_{∞}).

# Метод последовательных интервалов

## Суть метода

Численный метод: производную заменяют отношением конечных приращений за малый шаг Δt, и значения переменных вычисляют шаг за шагом от начальных условий:

$ i_{k+1} = i_{k} + (di/dt)_{k}·Δt.

Шаг выбирают, деля приблизительное время процесса на n интервалов (чем меньше шаг, тем точнее).

## Пример

Цепь R = 5 Ом, L = 10 мГн и нелинейный резистор u_{нэ} = 2i + 0,5i^{3} отключается от источника u = 15·sin 500t В. До коммутации i_{L}(t) = 2,121·sin(500t – 45°) А, поэтому i_{L}(+0) = i_{L}(–0) = –1,5 А и i_{нэ}(+0) = 1,5 А, u_{нэ}(+0) = 4,69 В. Уравнение после коммутации:

$ L·di_{нэ}/dt + R·i_{нэ} + 2i_{нэ} + 0,5·i_{нэ}^{3} = 0,

откуда i_{нэ k+1} = i_{нэ k} – (7·i_{нэ k} + 0,5·i_{нэ k}^{3})·Δt/0,01. Приблизительно τ = L/(R + u_{нэ}(0)/i_{нэ}(0)) ≈ 1,23 мс, время процесса 4τ ≈ 5 мс, его делят на 1000 интервалов. Расчёт удобно вести в Mathcad; результат близок к полученному методом кусочно-линейной аппроксимации.

> Метод последовательных интервалов – численное интегрирование малыми шагами: i_{k+1} = i_{k} + (di/dt)_{k}Δt.
> Шаг – доля приблизительного времени процесса (≈ 4τ); метод универсален, но требует вычислений на компьютере.
