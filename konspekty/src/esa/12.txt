= ВВЕДЕНИЕ

Комбинационные устройства средней степени интеграции выполняют типовые операции над кодами. В лекции рассмотрены дешифраторы (в том числе двоично-десятичный для десятичного и семисегментного индикатора), шифраторы, преобразователи кодов, мультиплексоры и демультиплексоры, полусумматор и полный сумматор.

# Дешифраторы и шифраторы

## Дешифратор

Дешифратор – комбинационное устройство, преобразующее n-разрядный двоичный код в сигнал на одном из 2^{n} выходов (код «1 из N»): активен выход, номер которого равен входному коду. Каждый выход реализует конъюнкцию входных переменных (минтерм). Полный дешифратор имеет 2^{n} выходов, неполный – меньше (например, двоично-десятичный 4×10). Обычно есть входы разрешения (стробирования), позволяющие наращивать разрядность и подавлять ложные сигналы при переходных процессах. Применяется для выбора ячейки памяти и устройства по адресу, распределения сигналов.

## Дешифраторы двоично-десятичного кода

Дешифратор 8-4-2-1 для выхода на индикатор десятичной цифры имеет 4 входа и 10 выходов: каждый активен при коде своей цифры (0–9), комбинации 1010–1111 не дешифрируются. Дешифратор для семисегментного индикатора преобразует тетраду в 7 сигналов сегментов a–g: например, цифра 1 – сегменты b, c; цифра 8 – все сегменты. Это по существу кодопреобразователь; учитывают тип индикатора (с общим анодом – активный уровень 0, с общим катодом – 1).

## Шифратор

Шифратор – обратное устройство: сигнал на одном из N входов преобразует в двоичный код номера этого входа. Приоритетный шифратор при одновременной активности нескольких входов выдаёт код входа с наибольшим приоритетом (старшего номера) – применяется в клавиатурах и системах прерываний. Преобразователь десятичного числа (нажатой клавиши 0–9) в код 8-4-2-1 – шифратор 10×4.

## Преобразователи кодов

Кодопреобразователь переводит код одного вида в другой: например, из двоичного в двоично-десятичный, из 8-4-2-1 в код Грея (g_{3} = b_{3}, g_{i} = b_{i} ⊕ b_{i+1} – на элементах исключающее ИЛИ) и обратно, в семисегментный код. Реализуется на логических элементах по таблице истинности или на ПЗУ (адрес – входной код, содержимое – выходной).

> Дешифратор: n входов → один из 2^{n} выходов; шифратор – обратное; приоритетный шифратор выдаёт старший активный вход.
> Кодопреобразователи 8-4-2-1 → код Грея, семисегментный – по таблице истинности или на ПЗУ.

# Мультиплексоры и демультиплексоры

## Мультиплексор

Мультиплексор – устройство, подключающее к одному выходу один из N информационных входов по n-разрядному адресу (N = 2^{n}): Y = Σ D_{i}·m_{i}, где m_{i} – минтерм адреса. Есть вход разрешения. Применение: коммутация каналов, преобразование параллельного кода в последовательный, реализация произвольной логической функции n переменных – переменные подают на адресные входы, а на информационные – константы 0 и 1 по таблице истинности.

## Демультиплексор

Демультиплексор – обратное устройство: передаёт сигнал с одного входа на один из N выходов, выбранный адресом. Схемно это дешифратор, у которого вход разрешения используется как информационный вход.

> Мультиплексор: один из 2^{n} входов на выход по адресу; реализует любую функцию n переменных.
> Демультиплексор – дешифратор с информационным входом разрешения.

# Сумматоры

## Полусумматор и полный сумматор

Полусумматор складывает два одноразрядных числа A и B: сумма S = A ⊕ B, перенос P = A·B; он не учитывает перенос из младшего разряда. Полный одноразрядный сумматор учитывает входной перенос P_{вх}:

$ S = A ⊕ B ⊕ P_{вх};  P_{вых} = A·B + P_{вх}·(A ⊕ B).

Его строят из двух полусумматоров и элемента ИЛИ. Многоразрядный сумматор: последовательный перенос – цепочка полных сумматоров (просто, но задержка растёт с разрядностью); параллельный (ускоренный) перенос – отдельная схема одновременно формирует переносы для всех разрядов. Четырёхразрядные сумматоры с ускоренным переносом выпускают в виде микросхем; вычитание выполняют сложением с дополнительным кодом вычитаемого.

> Полусумматор: S = A ⊕ B, P = AB; полный сумматор учитывает входной перенос.
> Многоразрядный сумматор – с последовательным или ускоренным переносом; вычитание – через дополнительный код.
