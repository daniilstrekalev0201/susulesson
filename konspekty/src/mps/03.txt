@title Комбинационные устройства: дешифраторы, шифраторы, мультиплексоры, сумматоры, компараторы, АЛУ

= ВВЕДЕНИЕ

Комбинационное устройство – устройство, выходы которого в каждый момент определяются только текущими значениями входов (памяти нет). В лекции рассмотрены дешифраторы (включая дешифратор семисегментного индикатора), шифраторы, мультиплексоры и демультиплексоры, сумматоры, цифровые компараторы и арифметико-логическое устройство.

# Дешифраторы и шифраторы

## Дешифратор

Дешифратор преобразует n-разрядный двоичный код в сигнал на одном из 2^{n} выходов. Типы: полные (2^{n} выходов, например 3×8), неполные (двоично-десятичный 4×10); с прямыми и инверсными выходами; со входами разрешения (стробирования) для наращивания разрядности. Применение: выбор ячейки памяти или устройства по адресу, управление индикаторами, распределение сигналов. На УГО обозначается DC.

## Дешифратор семисегментного индикатора

Семисегментный индикатор содержит сегменты a–g (и точку); дешифратор переводит тетраду (0–9 или 0–F) в семь сигналов сегментов: цифра 0 – a, b, c, d, e, f; цифра 1 – b, c; цифра 8 – все. Для индикатора с общим катодом активный уровень 1, с общим анодом – 0. На микроконтроллере дешифратор реализуют таблицей кодов в ОЗУ или ПЗУ: входной код используют как смещение адреса, считанный байт выводят в порт индикатора.

## Шифратор

Шифратор (CD) преобразует активный сигнал на одном из N входов в двоичный код номера входа (например, 8×3, 10×4). Приоритетный шифратор при нескольких активных входах выдаёт код старшего по приоритету и сигнал наличия активного входа; применяется в клавиатурах и контроллерах прерываний.

> Дешифратор: код → «1 из 2^{n}»; шифратор – обратно; приоритетный шифратор выбирает старший вход.
> Дешифратор семисегментного индикатора удобно делать таблицей кодов.

# Мультиплексоры и демультиплексоры

## Мультиплексор

Мультиплексор (MUX) подключает к выходу один из 2^{n} информационных входов по n-разрядному адресу; есть вход разрешения. Мультиплексор 4×1: Y = D_{0}·не A_{1}·не A_{0} + D_{1}·не A_{1}·A_{0} + D_{2}·A_{1}·не A_{0} + D_{3}·A_{1}·A_{0}. Применение: коммутация каналов, преобразование параллельного кода в последовательный, реализация произвольной комбинационной схемы – переменные подают на адресные входы, а на информационные – значения функции из таблицы истинности.

## Демультиплексор

Демультиплексор (DMX) передаёт сигнал с одного информационного входа на один из 2^{n} выходов по адресу; по схеме совпадает с дешифратором, у которого вход разрешения служит информационным.

> MUX: 2^{n} входов → 1 выход по адресу; реализует любую функцию n переменных. DMX – обратное устройство.

# Сумматоры, компараторы и АЛУ

## Сумматоры

Одноразрядный полусумматор: S = A ⊕ B, P = A·B (без входного переноса). Полный одноразрядный сумматор: S = A ⊕ B ⊕ P_{вх}, P_{вых} = A·B + P_{вх}·(A ⊕ B). Четырёхразрядный сумматор (SM) складывает два 4-битных числа с учётом входного переноса и выдаёт сумму и выходной перенос; с ускоренным переносом – быстрее. В микроконтроллере сложение выполняют команды ADD и ADC (с переносом) для многобайтных чисел.

## Цифровые компараторы

Компаратор сравнивает два двоичных числа и формирует сигналы A > B, A = B, A < B. Одноразрядный: (A = B) = не (A ⊕ B); (A > B) = A·не B; (A < B) = не A·B. Четырёхразрядный сравнивает разряды начиная со старшего: числа равны, если равны все разряды; A > B, если в первом несовпадающем старшем разряде A = 1. Есть входы каскадирования для наращивания разрядности. В AVR сравнение выполняют командами CP и CPI с последующими условными переходами по флагам Z, C, N, V.

## Арифметико-логическое устройство

АЛУ – комбинационное устройство, выполняющее над двумя операндами одну из множества арифметических (сложение, вычитание, инкремент) и логических (И, ИЛИ, исключающее ИЛИ, инверсия) операций, выбираемую кодом операции на входах выбора функции; формирует результат и признаки (перенос, ноль, знак). Разрядность наращивают каскадированием АЛУ со схемой ускоренного переноса. АЛУ – центральный узел процессора микроконтроллера.

> Полный сумматор: S = A ⊕ B ⊕ P_{вх}; компаратор даёт A > B, A = B, A < B.
> АЛУ выполняет арифметические и логические операции по коду операции – основа процессора.
