# Бот группы ЮУрГУ: пары и сроки сдачи

Telegram-бот (aiogram 3) присылает:
- утром (07:00 по Челябинску) — пары на сегодня и что сдавать в ближайшие 3 дня;
- вечером (20:00) — пары на завтра;
- за 3 дня, за день и за 3 часа до срока — напоминание о сдаче;
- о новых заданиях в edu.susu.ru;
- по желанию — за 15 минут до каждой пары.

Кнопки: 📅 Сегодня, 📆 Завтра, 🗓 Неделя, 📚 Сдачи, ⚙️ Уведомления. Бота можно добавить и в общий чат
группы — там работают команды /today /tomorrow /week /dz /settings.

## Откуда данные
- **Расписание** — страница группы на www.susu.ru/ru/raspisanie-zanyatiy (обновляется раз в 3 часа).
- **Сроки сдачи** — «Электронный ЮУрГУ» (edu.susu.ru): бот входит под логином «Универиса»
  и берёт сроки из календаря курсов (раз в час).
- **ДЗ вручную** — админ нажимает «➕ Добавить ДЗ»: предмет → что сделать → срок.

## Переменные (Bothost → Переменные)
| Переменная | Что это |
|---|---|
| `BOT_TOKEN` | токен от @BotFather |
| `GROUP` | группа, как на сайте, например `КЭ-101` (можно поменять в боте: `/group КЭ-101`) |
| `ADMIN_IDS` | Telegram ID админов через запятую (свой ID — `/myid`) |
| `EDU_LOGIN`, `EDU_PASSWORD` | логин и пароль «Универиса»; без них — только расписание и ДЗ вручную |

Команды админа: `/status`, `/refresh`, `/group`, `/add`.
